# ConceptDive content

Thư viện bài mẫu cho app ConceptDive (Android): bài giải thích khái niệm Android, Kotlin, JVM, OOP và kiến trúc, kèm sơ đồ.

## Dùng trong app

Mở tab **Thư viện** → **Nguồn GitHub**, dán link repo này rồi chọn bài muốn tải:

```
https://github.com/zitsieunhan1512/ConceptDive-content
```

## Góp ý

Thấy sai sót hay muốn đề xuất bài mới, hãy [mở issue](https://github.com/zitsieunhan1512/ConceptDive-content/issues). Trong app, nút **Góp ý bài này** mở sẵn issue kèm tên bài.
